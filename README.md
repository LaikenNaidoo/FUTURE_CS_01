# FUTURE_CS_01
# Web Application Security Assessment

## Overview
This repository contains a web application vulnerability assessment conducted using OWASP ZAP.

## Target
http://testphp.vulnweb.com

## Scope
Passive security testing only. No exploitation performed.

## Key Findings
- Absence of Anti-CSRF Tokens (Medium)
- Security Header Misconfigurations
- Information Disclosure via HTTP Headers

## Tools Used
- OWASP ZAP
- Nmap

The full report is available in this repository.
